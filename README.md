## How to run

```sh
python3 main.py
```

`main.py` (pure Python 3.13 standard library, no dependencies) writes the line — exactly, with no trailing newline — to `/output/entry.txt`, then re-reads it and asserts it is UTF-8, 1–200 characters, not only whitespace, and exactly the line above. It prints the sha256 of `entry.txt`.
